# Personal Portfolio Website

This repository hosts my personal portfolio website showcasing my mechanical engineering projects, including my capstone and featured work.

## About

- Built with simple HTML and CSS.
- Hosted and deployed via GitHub Pages.
- Contains project writeups and related resources (PDFs).

## Updating

To update the site:

1. Edit or add project HTML pages or update the index.html.
2. Replace or add new PDFs and assets in the repository.
3. Commit and push changes to trigger GitHub Pages deployment.
